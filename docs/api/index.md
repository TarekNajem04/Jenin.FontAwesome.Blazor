# Jenin.FontAwesome.Blazor API Reference

Generated API reference for the Jenin.FontAwesome.Blazor packages, produced from the XML
documentation shipped with the assemblies.

## Packages

- **Jenin.FontAwesome.Blazor** — Font Awesome Free 7.3.1 components for ASP.NET Blazor.
- **Jenin.FontAwesome.Blazor.IconPicker** — optional icon metadata, search, and the `IconPicker` component.
- **Jenin.FontAwesome.Blazor.Icons** — optional pre-built per-icon preset components.
- **Jenin.FontAwesome.Blazor.Svg** — optional self-contained inline-SVG components (no Font Awesome runtime).
- **Jenin.FontAwesome.Blazor.Analyzers** — Roslyn analyzer and code fixes (`JFA1001`–`JFA1003`).
- **Jenin.FontAwesome.Blazor.MudBlazor** — MudBlazor icon-slot adapters.
- **Jenin.FontAwesome.Blazor.Blazorise** — Blazorise icon adapters.

(The `Jenin.FontAwesome.Blazor.Templates` pack is content-only and ships no API to document.)

# Jenin.FontAwesome.Blazor

Documentation hub for the Font Awesome Free 7.3.1 components for ASP.NET Blazor. This site is
generated from the same source tree as the packages and is deployed next to the
[live documentation site](https://tareknajem04.github.io/Jenin.FontAwesome.Blazor/).

## Start here

- [API reference](api/index.md) — every public type and member of the seven API-documented packages (the template pack ships no binaries to document), generated from the shipped XML docs.
- [Migration guides](migration/index.md) — per-source mappings verified by render tests.
- [Diagnostics](diagnostics.md) — analyzer IDs and what each one catches.
- [Pro setup](pro-setup.md) — licensed Font Awesome Pro styles and kits.
- [Hosting with kits](hosting-with-kits.md) — kit-based hosting without vendored assets.
- [Custom icons](custom-icons.md) — registering your own glyphs through the typed API.
- [UI suites](using-with-ui-suites.md) — MudBlazor, Blazorise, EasyAppDev, and Blazicons.
- [Gallery](gallery.md) — composed screens built from the component set.

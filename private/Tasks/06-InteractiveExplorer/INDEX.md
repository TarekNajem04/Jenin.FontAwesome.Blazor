# 06-InteractiveExplorer — Interactive Font Awesome Explorer (like fontawesome.com/search)

**Group status:** DONE
**Recommended model:** STRONG

An interactive, developer-friendly explorer for Jenin.FontAwesome.Blazor that lets users search icons, preview them with live controls (style/typeface, size, color, rotation/flip, animations, transforms, pull/mask/layers, duotone), inspect the generated Razor/markup, and copy snippets. The goal is a production-quality sample app (separate project) inspired by https://fontawesome.com/search but tailored to this library's API.
